# Sphinx TIL

Welcome! This repository is a globally-accessible external brain dedicated purely to explorations with the Sphinx documentation system. It has only two categories, one of which is for thoroughly-researched explorations of Sphinx that are sensible for real-world use. The other is for pure unadulterated fun. Perhaps you'll find the collection useful.

If you have a Sphinx quirk, edge-case, or pattern you'd like to see explored or if you have comments on, or suggestions for, any of the existing content, feel free to start a [discussion](https://github.com/Elliria/sphinx-til/discussions)!
